# APC Finance — Case Studies

A personal lending marketplace that connects borrowers to competing loan
offers from multiple partner lenders, earning an origination fee when a
loan funds. Case studies here draw from the `stg_apc_finance`,
`int_apc_finance`, and `mart_apc_finance` schemas in `db_portfolio`.
